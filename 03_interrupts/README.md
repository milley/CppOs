# 中断处理

实现 IDT（中断描述符表）和基本的硬件中断处理。

## 项目结构

```
03_interrupts/
├── bootloader.asm    # 引导程序
├── kernel_entry.asm  # 内核入口
├── kernel.c          # 主内核
├── idt.h / idt.c     # 中断描述符表
├── idt.asm           # IDT 汇编入口
├── idt_load.asm      # 加载 IDT
├── isr.h / isr.c     # 中断服务程序
├── isr.asm           # ISR 汇编入口
├── pic.h / pic.c     # 可编程中断控制器
├── timer.h / timer.c # 定时器驱动
├── io.h              # 端口 I/O
├── Makefile
└── README.md
```

## 快速开始

```bash
make
make run
```

## 功能

- 初始化 IDT（256 个中断入口）
- 初始化 PIC（主/从片）
- 设置定时器中断（100Hz）
- CPU 异常处理（0-31）
- IRQ 处理（32-47）

## 中断类型

| 类型 | 编号 | 说明 |
|------|------|------|
| CPU 异常 | 0-31 | 除零、页错误等 |
| IRQ | 32-47 | 硬件中断 |
| 定时器 | 32 | IRQ0 |
| 键盘 | 33 | IRQ1 |

## 关键概念

### IDT 入口结构（8字节）

```
┌─────────────────────────────────────┐
│  处理函数地址 [15:0]                 │
│  代码段选择子                        │
│  保留 (0)                            │
│  类型属性 (0x8E)                     │
│  处理函数地址 [31:16]                │
└─────────────────────────────────────┘
```

### 中断处理流程

```
硬件中断 → PIC → CPU → IDT → ISR → 处理 → EOI → 返回
```

### PIC 初始化

```
主片: IRQ 0-7  → 中断 32-39
从片: IRQ 8-15 → 中断 40-47
```
