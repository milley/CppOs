# 保护模式内核

从 16 位实模式切换到 32 位保护模式，并运行 C 语言内核。

## 项目结构

```
02_protected_mode/
├── bootloader.asm    # 引导程序 + 模式切换（汇编）
├── kernel_entry.asm  # 内核入口（汇编）
├── kernel.c          # 内核主体（C 语言）
├── Makefile          # 构建脚本
└── README.md
```

## 快速开始

### 编译

```bash
make
```

### 运行

```bash
# 图形窗口模式
make run

# 命令行模式
make run-cli
```

## 核心流程

```
┌─────────────────────────────────────┐
│  1. BIOS 加载引导扇区到 0x7C00       │
│  2. 加载内核扇区到 0x7E00            │
│  3. 启用 A20 线                      │
│  4. 加载 GDT                         │
│  5. 设置 CR0.PE = 1                  │
│  6. 远跳转到保护模式                 │
│  7. 设置数据段寄存器                 │
│  8. 跳转到 C 内核                    │
└─────────────────────────────────────┘
```

## 关键概念

| 概念 | 说明 |
|------|------|
| GDT | 全局描述符表，定义内存段属性 |
| A20 | 地址线，启用后可访问 1MB 以上内存 |
| CR0.PE | 保护模式使能位 |
| 段选择子 | 索引 GDT 的选择器（0x08=代码段, 0x10=数据段） |

## 内存布局

```
0x7C00        引导扇区加载位置
0x7E00        内核代码位置
0x90000       栈顶位置
0xB8000       显存起始位置
```
